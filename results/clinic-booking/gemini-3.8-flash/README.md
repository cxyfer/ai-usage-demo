# ☀️ 晴日心理諮商所 - 線上預約系統

這是一個專為「**晴日心理諮商所**」打造的輕量化、免安裝預約展示系統。

## 🌟 系統特色

1. **零安裝、雙擊即可開啟**：完全使用純原生 HTML、CSS 與 JavaScript，無需安裝 Node.js、Python 或任何伺服器環境。
2. **直覺的個案預約流程**：
   - 瀏覽 3 位心理師（陳晴予、林子翔、黃詠馨）之專長、簡介與執照資訊。
   - 自由選擇心理師、諮商空間（森林室、暖陽室、線上諮商）、預約日期與 50 分鐘會談時段。
   - 填寫個案姓名、聯絡電話與諮商需求後送出。
3. **即時時段衝突防護（雙重防護）**：
   - **心理師時段衝突**：同位心理師在同一個時段僅能接待一位個案，已被預約的時段會自動標示為「🔒 已額滿」並停用。
   - **實體諮商室衝突**：森林室與暖陽室在同一個時段無法同時重複借用。
4. **管理者專屬後台**：
   - 即時統計：待確認預約數、已確認成立數、今日諮商場次、累計總數。
   - 新預約預設顯示為「**待確認**」。
   - 管理者可一鍵點選「**✓ 確認預約**」讓預約正式成立，或點選「**✕ 取消預約**」釋出時段供他人預約。
   - 支援依「姓名、電話、預約編號」即時搜尋與狀態篩選。
5. **資料集中管理（好找好改）**：
   - 所有心理師、諮商室、營業時間、可預約時段皆集中在 [`data.js`](data.js) 檔案中。
   - 內含清楚中文註解，只要用任何文字編輯器打開即可修改。
6. **手機與桌面自適應（RWD）**：
   - 溫暖舒緩的燕麥色、大地綠與暖陽金配色，兼顧行動裝置流暢操作。

---

## 🚀 快速開始使用

1. 使用檔案總管，在資料夾中找到 **`index.html`**。
2. **直接對 `index.html` 雙擊滑鼠左鍵**，即會自動在預設瀏覽器（Chrome、Edge、Safari、Firefox 等）中開啟。

---

## 📂 檔案架構說明

| 檔案名稱 | 說明 |
| :--- | :--- |
| **`index.html`** | **主要入口網頁**（雙擊此檔案開啟）。包含前台預約介面與管理者後台。 |
| **`data.js`** | **資料設定檔**。集中管理心理師、諮商室、時段與示範資料。 |
| **`style.css`** | **視覺風格樣式表**。溫暖安心的療癒視覺與響應式排版。 |
| **`app.js`** | **預約系統邏輯核心**。負責時段防衝突演算法、瀏覽器儲存（LocalStorage）與後台操作。 |

---

## ✏️ 如何修改資料（心理師、空間、時段）？

打開 **`data.js`**，您會看到頂部有清楚的「修改指南」：
- **修改心理師**：在 `counselors` 陣列中修改姓名、專長標籤（`specialties`）、簡介（`intro`）。
- **修改空間**：在 `rooms` 陣列中修改諮商室名稱、容納形式或描述。
- **修改時段**：在 `timeSlots` 陣列中增加或刪除時段。
- **修改完成後**：儲存檔案，在瀏覽器中按 `F5` 或「重新整理」即可立即生效！
