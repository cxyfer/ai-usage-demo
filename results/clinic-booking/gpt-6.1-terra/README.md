# 晴日心理諮商所示範網站

直接雙擊 `index.html`，使用瀏覽器開啟即可，不需要安裝或啟動伺服器。

## 試用

1. 在首頁選擇心理師、日期、時間及諮商方式，填寫姓名和電話後送出。
2. 點右上方的「預約管理」，可以確認或取消預約；取消後時段會重新開放。
3. 預約只存在同一台裝置、同一個瀏覽器的本機資料中。清除瀏覽器資料可能一併刪除預約。

## 修改示範資料

用文字編輯器開啟 `data.js`，可修改心理師介紹、照片路徑、諮商方式及可預約時段。每位心理師與諮商方式的 `id` 請保持唯一；已有預約時，避免修改或重複使用原有 `id`。

預設照片是合成的示範人物。更換照片時，把圖片放進 `assets` 資料夾，修改對應的 `photo` 路徑，並將 `photoSize` 改為 `"cover"`、`photoPosition` 改為 `"center"`。

## 示範限制

網站沒有伺服器、登入、通知或跨裝置同步功能，不能防止不同瀏覽器或裝置之間重複預約，也不適合儲存真實個案資料或當作正式預約系統使用。
