# 示範用提示詞：用 Claude Code / Codex 做出診所預約網站

給不懂程式的觀眾示範用。在一個空資料夾裡開啟 Claude Code / Codex，依序貼上下面的提示詞。

## ① 主提示詞

```
我經營一間小型心理諮商診所，叫做「晴日心理諮商所」，想要一個讓個案可以線上預約的網站。

個案可以：
- 看到診所有哪些心理師，包含照片位置、專長和簡短介紹（先用 3 位假的心理師，之後我再改）
- 選擇心理師、日期時間和諮商室，填寫姓名、電話後送出預約
- 已經被預約的時段不能再選

諮商室有：森林室、暖陽室，另外也提供「線上諮商」。

我（管理者）可以：
- 在後台看到所有預約，並可以「確認」或「取消」
- 新預約先顯示「待確認」，我確認後才算成立

網站風格希望溫暖、安心、簡潔，手機上也要好用。

其他要求：
- 請做成不需要安裝任何東西、直接雙擊就能用瀏覽器打開的網頁
- 心理師、諮商室、可預約時段這些資料，請集中放在一個好找的檔案裡，方便我自己修改
- 這是示範版，後台先不用登入，資料存在瀏覽器裡就好

需求大致就是這樣，請直接做出來。做完後請自己打開檢查一次，再用簡單的話告訴我：要打開哪個檔案、怎麼試用。
```

> 想讓觀眾看到 AI 會先提問時，把「請直接做出來」改成「有不清楚的先問我」。

## ② 改內容

```
把第一位心理師改名叫「張雅婷」，專長改成「青少年議題、學業壓力」。
```

## ③ 改外觀

```
整體主色改成淡藍色，看起來更安靜一點。
```

## ④ 加通知

```
有人預約時，在後台跳出提醒，並在預約旁邊標示「新」。之後我想改成寄 Email 通知心理師，請先預留這個位置，告訴我之後要怎麼接。
```

## ⑤ 真正上線（進階）

```
現在我想讓別人從自己的手機預約、我在後台看得到。請幫我把資料改存到線上資料庫，後台加上登入密碼，並放到 Cloudflare 上。我有 Cloudflare 帳號，需要我操作的步驟請一步一步帶我做。
```

## 示範前檢查清單

- [ ] 事先用主提示詞跑過一次，確認大約需要多少時間
- [ ] 準備一個空資料夾，在裡面開啟 Claude Code / Codex
- [ ] 想讓 AI 自己開瀏覽器檢查的話，先執行 `npx playwright install chrome`
- [ ] AI 要求執行指令（例如開瀏覽器測試）時會跳出權限確認，向觀眾說明這是安全機制，按同意即可；拒絕的話它會跳過自我檢查
- [ ] 主提示詞約需 4～5 分鐘，可以趁這段時間解說提示詞的寫法
- [ ] 要示範第 ⑤ 步的話，先登入 Cloudflare 帳號
- [ ] 提醒觀眾：示範版請勿輸入真實個案資料

## 為什麼這樣寫

| 寫法 | 原因 |
|---|---|
| 寫上診所名稱、諮商室、「待確認 → 確認」流程 | AI 原本會先問這些，先寫好就不用現場等待 |
| 「雙擊就能打開」，不寫技術名詞 | 避免 AI 選擇需要 `npm install` 的做法，結果更穩定 |
| 「資料集中在一個好找的檔案」 | 示範修改時，觀眾看得懂 AI 改了什麼 |
| 明寫「示範版，不用登入、存在瀏覽器」 | 先把範圍說清楚，避免 AI 自己加後端 |
| 「做完自己打開檢查」 | 讓觀眾看到 AI 會自己驗證 |
| 第 ⑤ 步明確提到「線上資料庫」 | 存在瀏覽器的資料無法跨裝置，只部署靜態網頁時，後台看不到別人的預約 |
